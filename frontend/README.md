# Mộc Tâm web frontend

React + TypeScript + Vite web frontend for the Mộc Tâm herbal tea shop. This is a separate project from the Expo mobile app in the parent `frontend/` folder.

## Run

```sh
npm install
npm run dev
```

Then open the local URL printed by Vite. Use `npm run build` to create a production build and `npm run preview` to preview it locally.

## Planned structure

The web version will reuse the mobile app’s product concept, typography, colors, imagery, and shopping flows while using web-specific routing and responsive layouts.
